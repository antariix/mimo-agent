## sys_check.py

Displays system information including:
- Operating system name
- CPU core count
- RAM utilization percentage

**Requirements:**
```bash
pip install psutil
```

**Usage:**
```bash
python sys_check.py
```

**Example Output:**
```
OS: Windows
CPU Cores: 18
RAM Utilization: 74.7%
```
